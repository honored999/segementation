## Approved design

- Add preview subcommand using existing source/raw/targets/baseline protection arguments, plus --run (completed joint directory), --checkpoint-sha256 (independently supplied lowercase hash), --output (fresh external directory), --gpu physical index and optional --patient-limit default4, bounded1..61.
- Preview current completed joint.pt only, supporting current cold-start or pretrained-GD joint classifications. Not gan.pt, old offline checkpoints, partial/failed runs or interrupted-run resume.
- Validate complete receipt, checkpoint hash, format/classification, model config, pinned upstream identity, unchanged target identity/hash, exact fixed61/15/19 memberships and saved inner61 scaling. Use safe weights_only=True CPU loading with hash-before/after from same handle. Validate generator state and both alpha tensors (keys, shapes, dtype, finite values) before copying. Restore every architecture alias and eval/frozen BN. Do not construct D/S/optimizers or call training steps. torch.load may deserialize D/S tensors on CPU as part of existing joint.pt; explicitly distinguish that from constructing those models. Record saved implementation identities; do not demand old training implementation files equal the newly added preview implementation.
- Bound output to a fresh directory outside repository/source/raw/targets/baseline/run and ancestors. Hash/audit source inventories and input identities before/after; complete preview.json only after successful final audit. Preserve incomplete previews on failure, no manual completion marker.
- Use Cohort role checking BEFORE image/label loading, only sorted saved inner61 IDs, first patient-limit. No refit_scale, no internal15/external19 arrays, no arbitrary case override. Per patient choose deterministic first positive plane and up to two valid empty planes (deduplicate); skip all-ignore planes and state missing categories. No lesion means no positive preview, not error if empty valid planes exist.
- Input binary lesion mask exactly aligned with target, without random flips/augmentation. Bottom/right pad to multiple256 as existing training, no resize/reorientation. Generator output is in minus1/plus1 coordinates; invert using saved inner61 scaling, crop padding to native H/W. Invalid label-1 pixels remain explicitly excluded/black display, not fake anatomy.
- Four-panel PNG: real3mm target, binary lesion target, generated DWI, generated+lesion overlay. Common fixed saved-scale window for real/generated, no per-panel auto-contrast or histogram equalization. Native panels unresized; titles via Pillow or existing low-dependency renderer pattern. Report display clipping counts/window in manifest; no numeric image transformation hidden as visual enhancement.
- preview.json records non-formal qualitative-only classification, checkpoint/receipt/source/target identities, selected patient/z/category/native dimensions, saved scaling/window/padding, output hashes and current preview implementation hash. Not a generated training dataset or formal image-quality/segmentation metric result.
